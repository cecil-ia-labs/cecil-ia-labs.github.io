# Cecil-IA Labs · Observatório Open Source

**Idioma:** [English](README.md) · [Português (Brasil)](README.pt-BR.md) · [Italiano](README.it.md)

**Pesquisa, código e ideias em órbita.**

Bem-vindo ao espaço aberto da **[Cecil-IA Labs](https://www.cecilialabs.com/)**. Combinamos curiosidade científica e engenharia de software para investigar hipóteses, desenvolver ferramentas úteis e publicar o conhecimento produzido.

**[Explorar o Observatório](https://cecil-ia-labs.github.io/)** · **[Conhecer o laboratório](https://www.cecilialabs.com/)** · **[Ver organização no GitHub](https://github.com/cecil-ia-labs)**

## O que você encontrará

Nosso catálogo reúne **sete repositórios públicos de software e duas publicações de pesquisa**. Entre as áreas estão interoperabilidade acadêmica, processamento de mídia, infraestrutura de IA, codificação de dados, educação e visualização.

### Projetos selecionados

- **[Lattes2ORCID](https://cecil-ia-labs.github.io/lattes2orcid/)** — Converta registros bibliográficos de um XML do Lattes para BibTeX diretamente no navegador.
- **[FFmpeg Media Toolkit](https://github.com/cecil-ia-labs/ffmpeg-dev)** — Fluxos reproduzíveis com FFmpeg, biblioteca TypeScript, CLI e skills para agentes.
- **[Quad-Dimensional DataMatrix](https://zenodo.org/records/23968974)** — Pesquisa experimental de representação espacial, cromática e temporal de dados.
- **[Distributed Martian Atmospheric CO₂ Processing Swarms](https://zenodo.org/records/22249025)** — Publicação conceitual sobre processamento distribuído da atmosfera marciana.

O [catálogo interativo](https://cecil-ia-labs.github.io/#projects) permite filtrar por tema e explorar a seleção completa.

## Por que compartilhamos

A ciência aberta depende de **reprodutibilidade, crítica responsável e reconhecimento autoral**. Publicamos código, protótipos e estudos exploratórios para que outras pessoas possam verificar premissas, aprender e desenvolver novas ideias. Um projeto no catálogo não é necessariamente revisado por pares nem pronto para produção. Consulte as licenças e a documentação de cada trabalho.

## Participe

Cada repositório possui sua própria documentação e canais de contribuição. O código deste Observatório utiliza a [licença MIT](LICENSE), sem estender essa licença aos trabalhos vinculados.

Para detalhes de implantação e manutenção, consulte as [notas técnicas](docs/DEVELOPMENT.md). A publicação é manual para controlar a utilização do GitHub Actions.
