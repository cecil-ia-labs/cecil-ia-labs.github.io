**Ricerca, codice e idee in orbita.**

Benvenuti nello spazio open source di **[Cecil-IA Labs](https://www.cecilialabs.com/)**. Uniamo curiosità scientifica e ingegneria del software per esplorare ipotesi, creare strumenti utili e condividere ciò che impariamo.

**[Esplora l'Osservatorio](https://cecil-ia-labs.github.io/)** · **[Scopri il laboratorio](https://www.cecilialabs.com/)** · **[Organizzazione GitHub](https://github.com/cecil-ia-labs)**

## Cosa troverai

Il catalogo comprende **sette repository software pubblici e due pubblicazioni di ricerca**: interoperabilità accademica, elaborazione multimediale, infrastrutture di IA, codifica dei dati, didattica e visualizzazione.

### Progetti selezionati

- **[Lattes2ORCID](https://cecil-ia-labs.github.io/lattes2orcid/)** — Trasforma le pubblicazioni esportate dal curriculum Lattes XML in BibTeX direttamente nel browser.
- **[FFmpeg Media Toolkit](https://github.com/cecil-ia-labs/ffmpeg-dev)** — Flussi FFmpeg riproducibili con libreria TypeScript, CLI e skill per agenti.
- **[Quad-Dimensional DataMatrix](https://zenodo.org/records/23968974)** — Ricerca sperimentale sulla rappresentazione spaziale, cromatica e temporale dei dati.
- **[Distributed Martian Atmospheric CO₂ Processing Swarms](https://zenodo.org/records/22249025)** — Pubblicazione concettuale sul trattamento distribuito dell'atmosfera marziana.

Nel [catalogo interattivo](https://cecil-ia-labs.github.io/#projects) puoi cercare e filtrare i lavori.

## Perché condividiamo

La scienza aperta si fonda su **riproducibilità, confronto critico e attribuzione delle fonti**. Condividiamo codice, prototipi e studi iniziali affinché altri possano esaminarli e svilupparli. La presenza nel catalogo non implica revisione tra pari né idoneità per la produzione. Ogni progetto mantiene la propria licenza e documentazione.

## Partecipa

Visita i repository per consultare il codice, aprire segnalazioni o proporre contributi. Il portale è distribuito con licenza [MIT](LICENSE), senza modificare le licenze dei progetti collegati.

Per i dettagli di sviluppo e pubblicazione, consulta le [note tecniche](docs/DEVELOPMENT.md). La pubblicazione è manuale per controllare l'uso di GitHub Actions.
